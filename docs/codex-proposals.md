# Codex proposals

Codex: if a design improvement needs a change outside `styles/**` or `assets/icons/**`
(for example new markup, a new class, a different layout structure, or new behavior),
**do not make that change**. Describe it here instead, and the owner will decide.

Use this format for each proposal:

```
## <short title>
- Screen / component:
- What you want to change and why:
- Files that would need to change:
- Suggested markup / class names:
```
