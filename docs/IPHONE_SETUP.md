# 在 iPhone 上使用 Expenses Tracker

## 1. 安装到主屏幕（一次就好）

1. 用 **Safari** 打开网址（见 `docs/DEPLOY.md`，格式是 `https://<你的 GitHub 用户名>.github.io/expenses-tracker/`）
2. 点底部的「分享」按钮 ⬆︎
3. 往下滑，选「添加到主屏幕」→ 名称会是「Expenses」→ 点「添加」
4. 之后**只从主屏幕的图标打开**。iOS 会把主屏幕 App 和 Safari 的资料分开存放，从主屏幕打开，资料更不容易被系统清掉

> 必须用 Safari；Chrome、LINE、WhatsApp 等 App 里的内置浏览器无法添加到主屏幕。

## 2. 第一次打开

引导页只有 3 步：
1. 简介
2. 预计每月收入、每月存款目标（收入不固定就填一个保守的数字，可以先跳过）
3. 住房（住家里 / 合租房间 / 整租单位）和交通（公共交通 / 摩托车 / 汽车）：用来调整吉隆坡的参考标准

如果在月中开始用，这个月的预算会按剩余天数折算，不会让「今天还能花」虚高。

## 3. 每天怎么记（3 秒）

- 点右下角 **＋** → 输入金额 → **点类别，就保存了**
- 要加备注、改日期、标记「创业」：在点类别**之前**先点上面对应的小按钮
- 常记的东西（例如「午餐 RM 12」）记过两次以上，会出现在「今天」页的「常用」，**点一下就记好**
- 记错了：弹出提示时点「撤销」；或在列表**向左滑**删除、**点一下**修改
- 收入：在记一笔画面上方切换到「收入」→ 输入金额 → 点「类型 ▾」选类型（会记住上次用的）→「保存收入」

## 4. 每月固定的项目（设一次就好）

「设置 → 固定项目 → 新增」：房租、手机月费、Netflix、健身房、薪水……
到了日子会自动记上；「今天还能花」也会先把还没扣的固定支出预留起来。

## 5. 每日提醒（免费，不需要任何权限）

网页 App 的推送通知需要服务器（会产生费用，资料也要经过第三方），所以改用 iPhone 自带功能：

**方法一：提醒事项**
1. 打开「提醒事项」，新增「记账 · 今天花了什么？」
2. 点「ⓘ」→ 打开「日期」和「时间」（建议 21:30）→「重复」选「每天」

**方法二：快捷指令自动化**
1. 「快捷指令」→「自动化」→「＋」→「特定时间」→ 21:30、每天、立即运行
2. 加入动作「显示通知」：「打开 Expenses 记一下今天的开销 ✍️」

小技巧：把 Expenses 图标放进 Dock。

## 6. 自动备份（很重要）

资料**只存在这台 iPhone**。以下情况会让资料消失：删除主屏幕图标、清除 Safari 网站资料、换手机前没备份。

「设置 → 备份」：
- **自动备份**：每日 / 每周 / 每月 / 关闭。iPhone 不允许网页 App 在背景运行，所以是在**你打开 App 时**检查，到时间「今天」页会提醒你，点一下完成
- **备份位置二选一**：
  - **iCloud 云盘**：到时间时「今天」页会出现「该备份了」，点一下 → 分享菜单选「存储到文件」→ iCloud 云盘
  - **Google Drive（加密）**：第一次连接时先登录 Google 授权，回到 App 后会给你一把 **28 位的恢复密钥**（例如 `K7QM-2XNP-…`）。
    请把它存到「密码」App 或上锁的备忘录，然后再输入一次确认。（如果这台手机还没有资料、而 Google Drive 里已有备份，App 会先问你要不要还原。）
    备份存在 Google Drive 里只有这个 App 能读的隐藏资料夹，**上传前先用恢复密钥加密**，Google 和其他人都看不到内容。
    Google 的授权约 1 小时过期，所以到时间时「今天」页会显示「备份到 Google Drive」：点一下，会闪过一下 Google 页面再自动回来完成备份
    （在自动上锁时间内回来不需要再解锁）。只保留最近 10 份，而且手机里没有资料时不会上传空备份
- **换手机**：新手机装好 App →「设置 → 从 Google Drive 还原」→ 登录 Google → 选备份 → 输入恢复密钥；还原后会继续用同一把恢复密钥备份。
  也可以「从备份文件还原」选 iCloud 里的文件
- **恢复密钥弄丢了**（手机还在）：「设置 → 备份 → 恢复密钥」换一把新的，App 会马上用新密钥备份一次；旧的备份仍需要旧密钥
- 「导出 CSV」可以用 Numbers / Excel 打开所有记录

## 7. 密码锁与 Face ID

「设置 → 安全」：
- **密码锁**：设一个 **6 位**密码（和 iPhone 一样）。以前设过 4 位的，可以用「改为 6 位密码」更新
- **Face ID 解锁**：打开后，iPhone 会询问是否为这个 App 保存「通行密钥」，确认即可。之后打开 App 会自动弹出 Face ID，失败或取消时可以输入密码。「密码」App 里会看到一个 Expenses Tracker 的通行密钥，请不要删除
- **自动上锁**：立即 / 1 分钟 / 5 分钟 / 15 分钟 / 1 小时，离开 App 超过这个时间就需要重新解锁；在 App 切换器里也看不到金额
- 密码只以加密杂凑的形式存在手机上，**忘记了无法找回**，只能清除资料后用备份还原，所以请记好
- Face ID 是「开门」用的：能挡住拿到你手机的人，但手机里的资料本身没有另外加密，iPhone 本身的锁屏密码仍然最重要

## 8. 分析页怎么看

- **吉隆坡 24 岁创业者对照**：你的个人生活费（不含创业投入）落在 精简 / 合理 / 偏高 / 过高 哪一段。
  参考来自 EPF《Belanjawanku 2024/2025》巴生谷单身标准（公共交通约 RM1,970、有车约 RM2,800，含储蓄）加上吉隆坡的实际租金行情
- **类别明细**：每个类别对照合理区间，标记「合理 / 偏高 / 过高 / 精简」
- **重点**：用白话告诉你本月最值得注意的 3～6 件事
- **与上月相比**：哪些类别多花了、哪些省了
- **个人 Runway**：填入「设置 → 目前存款」后，算出不靠收入还能撑几个月（建议至少 6 个月）

## 9. 投资页（RM 1,750,000 · 10 年 · 8–10%）

> 这是规划工具，不构成投资建议。回报率是你的假设，实际可能更高、更低，也可能亏损。

- **准备阶段**：还没有投入前，页面会追踪「月收入达到 RM 14,000」这个开始条件（按「记录」里的收入计算），达到后会提示你
- **开始**：点右上角 ＋ →「记录投入」，第一次可以同时建立持仓（例如「全球指数 ETF」）。**第一笔投入的日期就是 10 年期限的起点**
- **计划**：显示在 8% / 9% / 10% 回报假设下，每年初需要投入多少才能达标。默认用 **8%（保守）** 的金额作为你的计划，这样即使回报只有 8% 也能达标。「调整」可以改目标、年限、回报假设、投入频率（每年 / 每季 / 每月）、计划金额、开始条件
- **更新市值**：不定期（例如每月或每季）打开券商或银行 App，在「更新市值」一次填好每个持仓现在值多少。超过 45 天没更新会提醒你
- **实际表现**：App 会用你的投入 / 取出记录和最新市值，算出**实际年化回报**（资金加权），和 8–10% 对比。持有不到 1 年时，年化数字波动会很大
- **持仓明细**：点一个持仓可以看全部记录、投入、取出、更新市值、删除错误的记录（可撤销）
- 投资的钱**不算进「支出」**，也不影响「今天还能花」
