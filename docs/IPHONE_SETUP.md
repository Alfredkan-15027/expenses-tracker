# 在 iPhone 上使用 Expenses Tracker

## 1. 安装到主屏幕（一次就好）

1. 用 **Safari** 打开网址（见 `docs/DEPLOY.md`，格式是 `https://<你的 GitHub 用户名>.github.io/expenses-tracker/`）
2. 点底部的「分享」按钮 ⬆︎
3. 往下滑，选「添加到主屏幕」→ 名称会是「Expenses」→ 点「添加」
4. 之后**只从主屏幕的图标打开**。iOS 会把主屏幕 App 和 Safari 的资料分开存放，从主屏幕打开，资料更不容易被系统清掉

> 必须用 Safari；Chrome、LINE、WhatsApp 等 App 里的内置浏览器无法添加到主屏幕。

## 2. 第一次打开

引导页只有 3 步：
1. 简介
2. 预计每月收入、每月存款目标（收入不固定就填一个保守的数字，可以先跳过）
3. 住房（住家里 / 合租房间 / 整租单位）和交通（公共交通 / 摩托车 / 汽车）：用来调整吉隆坡的参考标准

如果在月中开始用，这个月的预算会按剩余天数折算，不会让「今天还能花」虚高。

## 3. 每天怎么记（3 秒）

- 点右下角 **＋** → 输入金额 → **点类别，就保存了**
- 要加备注、改日期、标记「创业」：在点类别**之前**先点上面对应的小按钮
- 常记的东西（例如「午餐 RM 12」）记过两次以上，会出现在「今天」页的「常用」，**点一下就记好**
- 记错了：弹出提示时点「撤销」；或在列表**向左滑**删除、**点一下**修改
- 收入：在记一笔画面上方切换到「收入」

## 4. 每月固定的项目（设一次就好）

「设置 → 固定项目 → 新增」：房租、手机月费、Netflix、健身房、薪水……
到了日子会自动记上；「今天还能花」也会先把还没扣的固定支出预留起来。

## 5. 每日提醒（免费，不需要任何权限）

网页 App 的推送通知需要服务器（会产生费用，资料也要经过第三方），所以改用 iPhone 自带功能：

**方法一：提醒事项**
1. 打开「提醒事项」，新增「记账 · 今天花了什么？」
2. 点「ⓘ」→ 打开「日期」和「时间」（建议 21:30）→「重复」选「每天」

**方法二：快捷指令自动化**
1. 「快捷指令」→「自动化」→「＋」→「特定时间」→ 21:30、每天、立即运行
2. 加入动作「显示通知」：「打开 Expenses 记一下今天的开销 ✍️」

小技巧：把 Expenses 图标放进 Dock。

## 6. 备份（很重要）

资料**只存在这台 iPhone**。以下情况会让资料消失：删除主屏幕图标、清除 Safari 网站资料、换手机前没备份。

- 「设置 → 立即备份」→ 分享菜单选「存储到文件」→ 存到 **iCloud 云盘**
- 建议每两周一次；超过 14 天没备份，App 会在「今天」页提醒你
- 换手机：新手机装好 App →「设置 → 从备份还原」→ 选那个备份文件
- 「导出 CSV」可以用 Numbers / Excel 打开所有记录

## 7. 密码锁（可选）

「设置 → 密码锁」：设一个 4 位密码。每次打开，或离开 App 超过 1 分钟，都需要输入；在 App 切换器里也看不到金额。
密码只以加密杂凑的形式存在手机上，**忘记了无法找回**，只能清除资料后用备份还原，所以请记好。

## 8. 分析页怎么看

- **吉隆坡 24 岁创业者对照**：你的个人生活费（不含创业投入）落在 精简 / 合理 / 偏高 / 过高 哪一段。
  参考来自 EPF《Belanjawanku 2024/2025》巴生谷单身标准（公共交通约 RM1,970、有车约 RM2,800，含储蓄）加上吉隆坡的实际租金行情
- **类别明细**：每个类别对照合理区间，标记「合理 / 偏高 / 过高 / 精简」
- **重点**：用白话告诉你本月最值得注意的 3～6 件事
- **与上月相比**：哪些类别多花了、哪些省了
- **个人 Runway**：填入「设置 → 目前存款」后，算出不靠收入还能撑几个月（建议至少 6 个月）
